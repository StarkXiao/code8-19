# 古树名木复壮跟踪系统

按株建立古树名木档案，记录体检结论与复壮措施，并在复壮完成后 **两年内持续跟踪存活情况**。

纯 Python 标准库实现（`http.server` + `sqlite3`），**无需安装任何第三方依赖**。

## 快速开始

```bash
cd tree-tracker
python3 seed.py     # 可选：写入演示数据（覆盖跟踪正常/待跟踪/期满/死亡/未复壮各状态）
python3 run.py      # 启动，默认 http://127.0.0.1:8000
```

自定义地址：`python3 run.py --host 0.0.0.0 --port 8080`

## 功能

| 模块 | 说明 |
| --- | --- |
| 工作台 | 统计卡片（建档数、跟踪期内、待跟踪提醒、体检异常）、待跟踪提醒列表、最近跟踪动态 |
| 古树档案 | 按株建档：编号、树种、拉丁名、树龄、保护级别、地点、经纬度、权属、状态、备注；支持搜索与筛选、CSV 导出 |
| 体检记录 | 体检日期、结论（健康/基本健康/衰弱/濒危）、树干/树冠/根系/病虫害、处理建议、体检人 |
| 复壮措施 | 措施类型、内容、开始/完成日期、实施单位 |
| 跟踪记录 | 跟踪日期、存活状态（存活/衰弱/死亡）、生长情况、记录人 |
| 档案时间线 | 单株页面按日期汇总展示全部体检、复壮、跟踪记录 |

## 业务规则

- **两年跟踪期**：以最近一次复壮措施的 *完成日期*（未填则用开始日期）起算两年。
- **跟踪频率**：跟踪期内每 6 个月至少登记一次跟踪记录，超期或期内从未登记的，进入工作台「待跟踪提醒」并以红色标识。
- **死亡联动**：跟踪记录选择「死亡」后，档案状态自动更新为「死亡」，并不再产生跟踪任务。
- **跟踪期满**：两年后状态自动转为「跟踪期满」，保留全部历史记录。

## 目录结构

```
tree-tracker/
├── run.py            # 启动入口
├── seed.py           # 演示数据
├── app/
│   ├── db.py         # SQLite 连接与建表
│   ├── domain.py     # 两年跟踪期、待跟踪判定等核心规则
│   ├── views.py      # 页面 HTML 渲染
│   ├── server.py     # HTTP 路由与请求处理
│   └── helpers.py    # HTML 转义
├── static/style.css
└── data/trees.db     # 数据库文件（首次启动自动创建）
```

## 数据说明

- 所有数据保存在 `data/trees.db`（SQLite），删除该文件即清空全部数据。
- 「导出 CSV」生成带 BOM 的 UTF-8 文件，可直接用 Excel 打开。
